# Kana handwriting reference data

`kana-templates.png` includes stroke-path reference images derived from
[KanjiVG](https://github.com/KanjiVG/kanjivg), copyright Ulrich Apel and
contributors, licensed under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).

KanaMaster generates this sprite with `scripts/generate_kana_assets.py` and
combines the stroke references with two locally rendered Japanese font
variants. The generated KanjiVG-derived portions remain available under the
same CC BY-SA 3.0 terms.
